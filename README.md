# Siddharth M Betadur — Finance Portfolio

Personal portfolio website for an MBA Finance profile.

## GitHub Pages setup

1. Create a **public** repository named `siddharthbetadur25-code.github.io`.
2. Upload `index.html`, `style.css`, and this README.
3. Upload your resume as `resume.pdf`.
4. Go to **Settings → Pages → Deploy from a branch → main → /(root)** and save.
5. Your portfolio will be available at `https://siddharthbetadur25-code.github.io/`.

## Before publishing
Replace the placeholder LinkedIn URL and email in `index.html`, and add `resume.pdf`.
